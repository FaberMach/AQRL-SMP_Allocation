# AQRL Roadmap

## v0.1.0 — Bootstrap
Establish repository structure, project identity, documentation contracts, and engineering standards.

## v0.2.0 — Core Infrastructure
Implement configuration, logging, events, registry, plugin manager, scheduler, exceptions, constants, and utilities.

## v0.3.0 — Data Layer
Implement data loaders, cache, feature store, canonical market state, and Yahoo Finance loader.

## v0.4.0 — Portfolio and Risk Engines
Implement portfolio construction, risk metrics, scenario analysis, and basic backtesting.

## v0.5.0 — Research OS
Implement experiment manager, model/policy registries, validation pipeline, and reproducibility layer.

## v0.6.0 — Regime Engine
Implement Hurst, volatility clustering, entropy, MF-DFA, and regime classification.

## v0.7.0 — Financial Game Theory
Implement Financial WOP-CFR and Financial PM-PSRO prototypes.

## v0.8.0 — Digital Twin
Implement synthetic market environment and agent simulation.

## v0.9.0 — Alpha Discovery
Implement evolutionary candidate search and strategy discovery workflows.

## v1.0.0 — Institutional MVP
Deliver an integrated, testable, dashboard-enabled AQRL research platform.
